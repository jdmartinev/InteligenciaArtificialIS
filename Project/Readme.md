# 🧠 Machine Learning / AI Project

## 📅 Timeline

### 🟡 Phase 1: Proposal (Anteproyecto)
**Due:** May 5  

Teams must submit a structured proposal including:

---

## 1. Problem & Idea
- What problem are you trying to solve?
- Why is it interesting or useful?
- Task type:
  - Classification / Regression / NLP / CV / etc.

---

## 2. Proposed Approach
- What methods or models do you plan to use?
  - (e.g., regression, decision trees, neural networks, embeddings + model, etc.)
- Brief explanation of why it makes sense

> ❗ It does not need to be correct, but it must be coherent.

---

## 3. Data
- Dataset source
- What does it contain?
  - Features (X)
  - Target variable (y)
- Approximate size

---

## 4. Initial Exploration (EDA)
- What did you observe?
  - Distributions
  - Imbalance
  - Outliers or anomalies
- Include at least **1–2 plots**

---

## 5. Question & Objective

**Question:**
- Clear and specific

**Objective:**
- What you aim to achieve with the model

---

## 6. Evaluation
- How will you measure performance?
  - Accuracy, F1-score, RMSE, etc.
- Brief justification

---

## 7. References
- Minimum 2–3 sources (papers, blogs, documentation)

---

# 🔵 Phase 2: Final Project
**Due:** May 28 – 11:59 PM  

In this phase, teams must **implement, evaluate, and present** their project.

---

# 📄 Deliverables

Each team must submit the following:

---

## 1. Project Report (Max. 2 pages, PDF)

The report must include:

### Problem Statement
A brief description of the task, including context, objective, and dataset used.

### Model Architecture
Describe the model used or implemented. Include layers, key components, and design decisions (e.g., CNN, transformer, etc.).

### Training Procedure *(if applicable)*
Include:
- Optimizer  
- Learning rate  
- Epochs  
- Batch size  
- Loss function  
- Hardware used (optional)

### Results
Include:
- Key metrics (e.g., accuracy, F1-score)
- Training/validation curves
- Insights from evaluation

---

## 2. Video Presentation (Max. 10 minutes)

The video must include:

- Problem and motivation  
- Model explanation  
- Training and testing process  
- Key results  
- Lessons learned or future work  

---

## 3. Code Repository (GitHub or similar)

The repository must include:

- A clear `README.md` with instructions to run the code  
- Training and evaluation scripts  
- Pretrained models or checkpoints (if applicable)  
- `requirements.txt` or `environment.yml`  

---
